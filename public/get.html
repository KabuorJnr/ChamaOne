Get ChamaOne

Run your Chama with confidence — contributions, loans, meetings and books everyone can trust.

Open ChamaOne
Install on iPhone/iPad
  1. Tap the Share icon in Safari.
  2. Choose Add to Home Screen.
  3. Tap Add.
Add to your home screen
  1. Open the browser menu (⋮).
  2. Tap Install app / Add to Home screen.

Installing gives you a home-screen icon and a full-screen app — and it updates itself automatically, so you always have the latest ChamaOne.
